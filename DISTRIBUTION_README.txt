NETRUNNER NEXUS 0.2.0 PREVIEW 1
Windows 10/11 x64

Instale o aplicativo na pasta do seu usuário. O instalador não precisa de
permissão de administrador. Use o atalho criado no menu Iniciar para abrir.

Esta é uma versão de prévia. Alguns recursos de privacidade e segurança ainda
estão em desenvolvimento. A sandbox do Windows está desativada nesta versão;
não a use para navegação sensível.

O Netrunner Nexus inclui o CEF e o Chromium. Consulte THIRD_PARTY_NOTICES.md e
a pasta licenses para as licenças e créditos desses componentes.

Para remover, use "Aplicativos instalados" nas Configurações do Windows.
