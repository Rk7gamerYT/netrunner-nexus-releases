NETRUNNER NEXUS 0.3.0 PREVIEW 1
Windows 10/11 x64

Instale o aplicativo na pasta do seu usuário. O instalador não precisa de
permissão de administrador. Use o atalho criado no menu Iniciar para abrir.

Esta é uma versão de prévia. A sandbox do Windows e as principais proteções de
privacidade estão integradas. O cofre de senhas guarda dados localmente com
proteção do Windows; revelar, editar ou excluir exige Windows Hello configurado
(Windows 11). O preenchimento automático de senhas ainda não está disponível.

O instalador não possui assinatura digital de editor. O Windows pode exibir um
aviso de aplicativo não reconhecido. Confira o SHA-256 publicado antes de
instalar e use apenas os arquivos desta página oficial.

O Netrunner Nexus inclui o CEF e o Chromium. Consulte THIRD_PARTY_NOTICES.md e
a pasta licenses para as licenças e créditos desses componentes.

Para remover, use "Aplicativos instalados" nas Configurações do Windows.
